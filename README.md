# About

Geppetto is modeling software that exploits the Linux kernel's device topology, USB cable network, and localized module-specific file descriptors to generate a global model of arbitrary assemblies. This software was developed as part of a PhD thesis on modular reconfigurable robotic systems by Noel Khan at De Montfort University under the supervision of Dr. David Elizondo, Dr. Lipika Deka from Loughborough University, and Dr. Dr Miguel Ángel Molina Cabello of the University of Málaga. See the thesis titled "Disembodiment" for more details.
